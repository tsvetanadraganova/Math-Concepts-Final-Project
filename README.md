## Finding Efficient Delivery Routes with Python

### Project Overview

This project is developed as part of the SoftUni Math Concepts for Developers final exam.

The goal is to explore how mathematical concepts and Python can be used to find efficient delivery routes.

The project considers a simple delivery scenario with one warehouse and five delivery locations. A delivery vehicle must visit every location exactly once and return to the warehouse while minimizing the total travel distance.

### Mathematical Concepts

The project will explore:

- Euclidean distance between two points
- Total route distance
- Permutations and factorials
- Mathematical optimization

### Algorithms

Three route-finding approaches will be implemented and compared:

1. **Random Route** - Generates a random delivery route.
2. **Nearest Neighbor** - Selects the closest unvisited location at each step.
3. **Brute Force** - Evaluates all possible delivery routes to find the shortest one.
